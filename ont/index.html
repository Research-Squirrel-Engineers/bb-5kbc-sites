Description

Application ontology for the Brandenburg 5000 BC sites dataset (Schmidt 2026).

Data namespace

http://w3id.org/bb5kbc/

URI patterns

FID-based, per-site nodes:

  • site_{FID} → bb5kbc:Fundstelle
  • site_{FID}_activity → bb5kbc:GeoreferenzierungsAktivitaet
  • site_{FID}_geom → sf:Point
  • site_{FID}_culture → bb5kbc:KulturelleZuordnung (per-site connector to shared Kulturgruppe)
  • site_{FID}_dating → bb5kbc:Datierung (per-site, with site-specific start/end/certainty)

Hash-based (MD5(label_utf8)[:8]), deduplicated:

  • gemeinde_{hash} → bb5kbc:Gemeinde
  • kreis_{hash} → bb5kbc:Kreis
  • bundesland_{hash} → bb5kbc:Bundesland
  • land_{hash} → bb5kbc:Land
  • kultur_{hash} → bb5kbc:Kulturgruppe (shared concept node)
  • entdeckung_{hash} → bb5kbc:Entdeckung
  • entdeckungsart_{hash} → bb5kbc:EntdeckungsartType
  • fundstellenart_{hash} → bb5kbc:FundstellenartType
  • pub_{hash} → bb5kbc:Publikation
  • methode_{hash} → fsl:MethodType
  • quellentyp_{hash} → fsl:SourceType
  • datmethode_{hash} → bb5kbc:DatierungsMethodeType
  • sherd_{hash} → bb5kbc:Scherbe (hash from Wikidata QID)

External identifiers (TGN + iDAI + OSM) on all 4 administrative levels.

CM Literals (on bb5kbc:GeoreferenzierungsAktivitaet)

| CSV column | FSL property | FSL CM ID | Range | |---|---|---|---| | quelle_georef | fsl:hasReference / fsl:activityDesc | P25 | xsd:string | | QID_quelle_georef | fsl:hasReference | P31 | Wikidata URI | | methode | fsl:method / fsl:methodUsed | P7 | fsl:MethodType Named Node | | quellen_typ | fsl:hasSourceType + fsl:hasSourceTypeDetail | P6 + P16 | fsl:SourceType Named Node | | methodenbeschr | fsl:activityDesc | P15 | xsd:string | | genauigkeit_m | fsl:precision | P23 | xsd:decimal (on bb5kbc:Fundstelle) | | wgs84_x/y | geosparql:asWKT | — | on sf:Point (skip if both = 0,0) |

Datingc # Classes

URI http://w3id.org/bb5kbc/ont/Datierung
Description

Dating / time span of a bb5kbc:KulturelleZuordnung. URI: culture_{hash}_dating (derived from parent KulturelleZuordnung hash). One per Fundstelle. Dual superclass: time:Interval (for dating_start/end integers via time:hasBeginning / time:hasEnd + time:inXSDgYear) and crm:E52_Time-Span (for CIDOC CRM compatibility). Properties: bb5kbc:datierungStart xsd:integer (dating_start, BP or BCE/CE) bb5kbc:datierungEnd xsd:integer (dating_end) bb5kbc:datierungMethode → bb5kbc:DatierungsMethodeType (dating_method QID) bb5kbc:datierungSicherheitStart xsd:string (dating_certainty_start) bb5kbc:datierungSicherheitEnd xsd:string (dating_certainty_end) bb5kbc:datierungSicherheitRange xsd:string (dating_certainty_range, e.g. 'ca.') skos:exactMatch / skos:closeMatch / skos:relatedMatch → Perio.do URI (dating_perio.do + dating_perio.do_match determine which SKOS property)
Super-classes crm:E52_Time-Spanc

Physical archaeological site. Directly subClassOf crm:E27_Site ("piece of land in a particular configuration", CRM definition) as well as lado:Location and fsl:Site — both of which route through pleiades:Location → geosparql:SpatialObject → crm:E53_Place. crm:E27_Site is a subClassOf crm:E26_Physical_Feature → crm:E18_Physical_Thing → crm:E72_Legal_Object → crm:E70_Thing → crm:E1_CRM_Entity, and also via crm:E53_Place.
